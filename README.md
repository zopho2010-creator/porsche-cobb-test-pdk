# COBB Accessport / Porsche 981 研究归档

> **仅供测试 / For testing purposes only.** 本项目为独立研究，适用于离线分析和模拟验证。请勿用于实车刷写或公共道路车辆操作。

本仓库汇总 2026 年 11 月的两项研究。静态分析、公开资料和模拟结果分别注明来源与验证范围。

| 成果 | 内容 |
| --- | --- |
| [Accessport Manager 3.2.0](manager/README.md) | Windows 安装包和主程序的取得来源、签名与哈希，PE 分析器，以及 USB、固件更新和 Map 研究 |
| [POR-007 设备更新](manager/reports/firmware_download_path.md) | 公开更新镜像 1.8.0.0-29445 的历史下载记录、校验清单与车辆侧验证范围 |
| [Porsche 981 原型](porsche981/README.md) | J2534、ECU/PDK 软件识别、离线压缩编解码，以及备份与恢复的历史模拟结果 |

归档包含自研工具、合成测试和经过整理的证据。第三方程序、驱动、固件原件、受限 Map、原始车端记录和可执行的控制器授权及刷写流程保留在归档范围之外。本项目与 COBB Tuning、Porsche 无隶属关系。第三方商标及材料的权利归原权利人所有。
